# publications/ — luaran publikasi

Satu subfolder per luaran (mis. `paper-<jurnal>/`, `poster-<acara>/`), dibuat saat handoff-nya mulai dikerjakan.
Judul dan isi diputuskan pemilik proyek atas rekomendasi Lead (`LEAD.md` §8).

| Folder | Luaran | Handoff |
|---|---|---|
| `_bukti/H<nnn>/` | screenshot final (`ui`) & `metrik.md`/`.csv` (`data`) dari QA, dipakai bersama oleh semua luaran | QA tiap handoff |
